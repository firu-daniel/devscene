# The `graphscene` layer

> **Read this when:** the change you are implementing or reviewing lands under `graphscene/` — the GraphScene flow-graph navigation library, its four internal layers (`model`, `engine`, `adapters`, `facade`), its loading, its walker and state store, its shipped format-4 schema, its `pytest` suite or its `pyproject.toml`. **Skip when:** it lands anywhere else, harness-side code that drives GraphScene included: that goes in its own distribution outside `graphscene/`, below. The rules that span every layer are in `.claude/context/conventions.md`, which this document assumes has been read.

**Purpose.** The rules this layer's implementer and its reviewer both read before they start.

## What this layer owns, and what it is not

- **It owns the generic library and nothing harness-specific.** Reading the harness's configuration, executing its agents and its planning hooks go in a separate distribution outside `graphscene/`, named with a `devscene` prefix, which depends on `graphscene`; `graphscene` never depends on it, so extracting the library means moving this one directory (`graphscene/README.md` → `## The boundary`; `graphscene/src/graphscene/__init__.py` → module docstring). A task that needs any of those has drifted out of this layer. The cross-layer statement of this rule is `.claude/context/conventions.md` → `## The layers`.
- **The walker says what runs next and launches nothing**: running a node, rendering path templates, heartbeats, round files and what a host does with a review loop's round number, convergence and findings are the host's (`graphscene/README.md` → `## What it is`; `graphscene/src/graphscene/engine/transitions.py`, `graphscene/src/graphscene/engine/walker.py`, `graphscene/src/graphscene/engine/review_loop.py` → *"Deliberately not covered"*).
- **The library never logs or prints**: it reports through return values and exceptions only, so there is no logger accessor to use. A command-line entry point in `facade` is the one place that may write output (`graphscene/README.md` → `## The layers`, *"The library never logs or prints."*). How each part reports is `## Errors and the loading order` and `## The walk`.
- **It has no user interface and keeps no state of its own**, so it has no localization, theming or sizing accessors, no UI components or test attributes, no navigation or screen registries and no storage keys. A walk's state is written only where the caller's `StateStore` puts it; the caller chooses the store and hands it to `Walker` (`graphscene/README.md` → `## The layers`; `graphscene/src/graphscene/model/walk_state.py` → `StateStore`).
- **It owns its own toolchain configuration**: `graphscene/pyproject.toml` (its `[tool.importlinter]` contracts included) and `graphscene/uv.lock`. Gate 13's wiring and `scripts/python-service.sh` are not this layer's files (`docs/development.md` → `## 5. Verifying a change`, **Gate 13**).
- **It owns the format-4 flow-graph schema**, `graphscene/src/graphscene/schemas/flow-graph.schema.json`, shipped as package data and read through `importlib.resources.files("graphscene")`, never by a repository path (`graphscene/src/graphscene/adapters/schema.py` → `_validator`; `graphscene/tests/test_flow_graph_schema.py` → *"read through `importlib.resources`"*). The schema names no harness vocabulary (`graphscene/tests/test_flow_graph_schema.py` → `harness_names`, `test_the_schema_names_no_harness_vocabulary`). The harness's format-4 planning graph, `cli/templates/scripts/flows/task_plan_writing.v4.graph.json`, is validated against it from the repository root, so a schema change keeps that graph valid (`docs/development.md` → `## 5. Verifying a change`, **Gate 3**, leg `3g`; `docs/flow-graph-walker.md` → *Format 4* **Decision.**).

## What it may depend on

**The boundary.** Code under `graphscene/src/graphscene/` imports only the standard library, `graphscene` itself and the runtime dependencies `graphscene/pyproject.toml` declares under `[project] dependencies`. It names no `devscene`-prefixed module, even one that is declared; never names `devscene.config.json`; and `pyproject.toml` declares no `devscene`-prefixed dependency (`graphscene/README.md` → `## The boundary`; `graphscene/tests/test_boundary.py` → `scan`, `test_the_real_library_stays_inside_its_boundary`, `test_no_declared_dependency_is_devscene_prefixed`).

- **A relative import inside the package is always in bounds**, static or dynamic with a leading `.` or a non-zero `level` (`graphscene/tests/test_boundary.py` → `_dynamic_import_target`, `test_a_relative_dynamic_import_is_not_flagged`).
- **The gate does not see every import, and the rule still binds what it misses**: a module name computed at run time, an importer bound to another name (`from importlib import import_module as load`), a module name passed by keyword, and `builtins.__import__`. A reviewer checks those by reading them (`graphscene/tests/test_boundary.py` → module docstring, *"Deliberately not covered"*; `graphscene/tests/test_layers.py` → module docstring, *"Deliberately not covered"*).
- **A new runtime dependency is a decision raised to the maintainer, never one an implementing run makes**; adding a development tool to the `dev` dependency group is not restricted this way (`graphscene/README.md` → `## The boundary`).
- **A new runtime dependency whose import name differs from its normalised PEP 508 name gets an entry in `_IMPORT_NAMES`**, keyed by that normalised name — otherwise the boundary test flags the dependency's own imports (`graphscene/tests/test_boundary.py` → `_IMPORT_NAMES` and the comment above it).
- **`graphscene/tests/` is outside the scan** and may name the forbidden literal; the boundary binds `graphscene/src/graphscene/` (`graphscene/tests/test_boundary.py` → module docstring).

## The internal layers

The package is four layers. What each holds and may import is `graphscene/README.md` → `## The layers`, and each layer's `__init__.py` docstring restates its own import rule (`graphscene/src/graphscene/model/__init__.py`, `graphscene/src/graphscene/engine/__init__.py`, `graphscene/src/graphscene/adapters/__init__.py`, `graphscene/src/graphscene/facade/__init__.py` → *"The rule:"*).

| Layer | Path | May import |
|---|---|---|
| `facade` | `graphscene/src/graphscene/facade/` | `adapters`, `engine`, `model`, the standard library |
| `engine` | `graphscene/src/graphscene/engine/` | `model`, the standard library |
| `adapters` | `graphscene/src/graphscene/adapters/` | `model`, `jsonschema`, the standard library |
| `model` | `graphscene/src/graphscene/model/` | the standard library only |

- **Imports point down only, and `engine` and `adapters` never import each other.** Only `facade` combines them (`graphscene/pyproject.toml` → contract `graphscene-layers`).
- **`jsonschema` is imported in `adapters` only**, never in `model` or `engine` (`graphscene/pyproject.toml` → contract `graphscene-jsonschema-in-adapters-only`).
- **Both contracts are `import-linter` contracts in `graphscene/pyproject.toml` → `[tool.importlinter]`, run by `graphscene/tests/test_layers.py` with no cache.** A change to what a layer may import is a change to those contracts and to `graphscene/README.md` → `## The layers` together.
- **Callers import from `graphscene` only and never name `graphscene.facade`. No module inside the package imports from the package root**; each imports the defining module of what it needs (`graphscene/README.md` → `## The layers`; `graphscene/src/graphscene/__init__.py` → *"no module inside the package imports from the package root"*; `graphscene/src/graphscene/facade/loading.py` → its `from graphscene.model.errors import GraphError`).
- **New work goes by what it is.** A check or a walk over the model, and its rounds, goes in `engine`. A store, an executor or another format goes in `adapters`. A thin command-line entry point goes in `facade`. Walk state and checker findings, as plain types, go in `model` (`graphscene/README.md` → `## The layers`).
- **A `typing.Protocol` that an adapter implements and the engine drives is declared in `model`** — a state store, an executor, a host-answered predicate — so the adapter implements it without importing the engine; a caller satisfies it structurally, without subclassing (`graphscene/README.md` → `## The layers`; `graphscene/src/graphscene/model/__init__.py` → module docstring; `graphscene/src/graphscene/model/walk_state.py` → `StateStore`, `PredicateHost`; `graphscene/tests/model/test_walk_state.py` → module docstring).

## The public surface

- **The public surface is `__all__` in `graphscene/src/graphscene/__init__.py`, annotated `list[str]`, re-exported from `graphscene.facade`.** `graphscene/src/graphscene/facade/__init__.py` → `__all__` holds exactly the package root's names, in its order (`graphscene/src/graphscene/facade/__init__.py` → *"The rule:"*; `graphscene/tests/test_public_surface.py` → `test_the_facade_exposes_exactly_the_root_surface`).
- **`__all__` is compared as a list, so adding, removing or reordering a name is a reviewed change**, and each public name is the object its defining module defines (`graphscene/tests/test_public_surface.py` → module docstring, `_EXPECTED`, `_DEFINED_IN`).
- **The unvalidated builder is not public**: `build_flow_graph` stays out of `__all__`; a caller reaches the model only through `load_graph` or `load_graph_file` (`graphscene/tests/test_public_surface.py` → `test_the_unvalidated_builder_is_not_exported`).

## The model and its wire forms

- **The model is immutable**: every model, walk-state and walk-action class is a `@dataclass(frozen=True)`; a sequence is a `tuple` and a mapping a `types.MappingProxyType` over a fresh `dict`, keeping key order and never aliasing the caller's input (`graphscene/src/graphscene/model/flow_graph.py`; `graphscene/src/graphscene/model/walk_actions.py` → *"The rule:"*; `graphscene/src/graphscene/adapters/builder.py` → module docstring, *"Containers"*; `graphscene/tests/adapters/test_builder.py` → `test_the_model_is_immutable`, `test_mutating_the_input_after_the_build_leaves_the_graph_unchanged`).
- **In the graph, a serialized key maps to its attribute in snake_case** — `formatVersion` → `format_version`, `convergingFrom` → `converging_from`, `onCap` → `on_cap` — and every other key keeps its own name; a node's `id` is its key in `nodes` (`graphscene/src/graphscene/adapters/builder.py` → module docstring, *"Attribute names"*; `graphscene/tests/adapters/test_builder.py` → `test_every_optional_key_lands_on_its_snake_case_attribute`). A violation path keeps the serialized spelling (`graphscene/src/graphscene/engine/references.py`, `graphscene/src/graphscene/engine/vocabulary.py` → *"Paths use the serialized spelling"*).
- **An absent optional key is `None`**, except `held`, a `bool` that is `False` when absent; an integral number the schema accepts as an integer becomes an `int` (`graphscene/src/graphscene/adapters/builder.py` → module docstring, *"Absent keys"*, *"Integers"*).
- **The only fixed words are the schema's own enums, typed as `Literal` aliases** (`NodeKind`, `Primitive`, `Verdict`); a variant class carries its discriminator as a `ClassVar[Literal[...]]` named `kind`, never a field (`graphscene/src/graphscene/model/flow_graph.py` → module docstring, `DispatchNode.kind`; `graphscene/src/graphscene/model/walk_actions.py` → *"The rule:"*; `graphscene/tests/model/test_walk_actions.py` → module docstring).
- **References stay `str` ids**: the model resolves no node-id or other name reference, so the builder builds a graph whose ids do not resolve; checking that they exist is the static checker's, `graphscene/src/graphscene/engine/references.py` → `reference_violations`, run first inside `graphscene.static_violations` (`graphscene/src/graphscene/adapters/builder.py` → *"Deliberately not covered"*; `graphscene/tests/adapters/test_builder.py` → `test_references_stay_strings`).
- **The walk-state document is the other wire form, and it maps no case**: every key is the attribute's own name, the top level carries `"version": 1`, each action and passage object carries its `kind` first, and `None` is a `null` under a key that is always present. The codec reads only what it writes, refusing another version, a missing or extra key and an unknown `kind` with `ValueError("<path>: <reason>")`. A change to the document's shape raises `version`, and a document of an older version is refused, not migrated (`graphscene/src/graphscene/adapters/walk_json.py` → *"The rule:"*, `_VERSION`; `graphscene/tests/adapters/test_walk_json.py` → module docstring).

## Errors and the loading order

- **One error shape for every loading stage: `GraphError(stage, violations)`**, a `ValueError` carrying at least one `Violation(path, reason)`; `Stage` names the stage (`graphscene/src/graphscene/model/errors.py` → `GraphError`, `Stage`; `graphscene/README.md` → `## What it is`). A new rejecting stage is a new `Stage` member, never a second error type.
- **A violation's path names the node and the field, dotted from the graph root** — object keys joined with `.`, array indices as `[i]`, `""` for the root — and renders as `<path>: <reason>` (`graphscene/src/graphscene/model/errors.py` → *"The rule:"*, `Violation.__str__`).
- **A check returns `Violation` values; only the facade raises `GraphError` for a schema, vocabulary or static failure.** `schema_violations` never raises `GraphError` and returns its violations sorted by path then reason; `vocabulary_violations` returns its in document order; `static_violations` returns the reference violations alone when there are any, otherwise checks 1, 2, 3, 8 and 9 in that order, each reason opening with its check id (`<check-id>: <detail>`) (`graphscene/src/graphscene/adapters/schema.py` → `schema_violations`; `graphscene/src/graphscene/engine/vocabulary.py` → *"The rule:"*; `graphscene/src/graphscene/engine/static_check.py` → *"The rule:"*; `graphscene/src/graphscene/facade/loading.py` → `load_graph`). Reading a file raises a parse-stage `GraphError`, and an `OSError` propagates unchanged (`graphscene/src/graphscene/adapters/json_file.py` → *"The rule:"*).
- **The checks are total**: a graph built in code that an earlier stage would refuse never raises inside them; targets, bindings and outcome declarations are looked up with `.get` (`graphscene/src/graphscene/engine/static_check.py` → *"The checks are total"*).
- **The builder does not validate**: a shape the schema would have refused raises `TypeError` naming the dotted path, never a `GraphError` (`graphscene/src/graphscene/adapters/builder.py` → module docstring; `graphscene/tests/adapters/test_builder.py` → `test_the_builder_refuses_a_shape_the_schema_would_have_refused`).
- **Loading runs schema → build → vocabulary → static**: a returned graph has passed the schema, been built, then passed the vocabulary check and the static checks, and a graph failing one stage never reaches the next (`graphscene/src/graphscene/facade/loading.py` → *"The rule:"*; `graphscene/tests/facade/test_loading.py` → `test_a_schema_failure_never_reaches_the_vocabulary_stage`, `test_a_vocabulary_failure_never_reaches_the_static_stage`). **Every engine check reads the built `FlowGraph`**, never the parsed mapping (`graphscene/README.md` → `## The layers`).
- **A schema `pattern` is matched as ECMA-262**: `_ecma_pattern` translates the constructs it supports and refuses any other, naming its schema path, so a schema change using a new construct forces a decision about the translator (`graphscene/src/graphscene/adapters/schema.py` → `_ecma_pattern`; `graphscene/tests/adapters/test_schema.py` → `test_every_shipped_schema_pattern_is_translatable`).

## The walk

- **A walk refusal is a returned `Refused`, never an exception**, and a `Refused` leaves the store unwritten; the transitions raise nothing, and on a `Refused` the caller discards the draft (`graphscene/README.md` → `## The layers`, *"A walk refusal is a returned `Refused`"*; `graphscene/src/graphscene/engine/walker.py`, `graphscene/src/graphscene/engine/transitions.py` → *"The rule:"*).
- **The state store's errors are builtins, and `Walker` lets them propagate**: `FileStateStore` raises `ValueError` naming the state file for a malformed state and `TimeoutError` naming the `<name>.lock` file when the lock is not acquired within `lock_timeout` (`graphscene/README.md` → `## The layers`; `graphscene/src/graphscene/adapters/state_file.py` → `FileStateStore.read`, `FileStateStore.lock`).
- **The source of truth for a walk is the saved `WalkState`, read through the `StateStore`.** `start` and `next` hold the store's lock from before the read until after the write; `current` takes no lock, changes nothing and re-returns the saved pending action; only `start` replaces a saved walk, setting every counter and round number to 0; `next` and `current` refuse a walk of another flow (`graphscene/src/graphscene/engine/walker.py` → *"The rule:"*; `graphscene/tests/engine/test_walker.py` → module docstring).
- **A `WalkState` is a position, never a history; it is replaced whole and never mutated**, and its `pending` is exactly what `current` returns (`graphscene/src/graphscene/model/walk_state.py` → *"The rule:"*).
- **`FileStateStore` writes only its state file and the `<name>.lock` sibling**, replacing the file through a temporary file in the same directory and `os.replace` so an unlocked `read` never sees a torn document, and releases the lock in a `finally` (`graphscene/src/graphscene/adapters/state_file.py` → *"The rule:"*; `graphscene/tests/adapters/test_state_file.py` → module docstring).
- **Routing reads declared primitives only** — an outcome's `verdict`, the binding's class, the round's `records`, a predicate's `records` and `in_round_counts` — never a name (`graphscene/src/graphscene/engine/transitions.py` → *"Routing reads declared primitives only"*).
- **Skips are asked of the `PredicateHost` on every arrival, never from a cache**, and a predicate the host cannot answer is refused (`graphscene/src/graphscene/engine/transitions.py` → *"never from a cache"*).
- **The transitions rely on `load_graph`'s guarantees and never re-check them** (`graphscene/src/graphscene/engine/transitions.py` → *"A graph that did not pass `load_graph`"*).
- **A round is engine-generic**: it dispatches its unskipped gates as one set and joins them, and the round machinery lives in `transitions.py` and `rounds.py` (`graphscene/src/graphscene/engine/review_loop.py` → *"Deliberately not covered"*; `graphscene/src/graphscene/engine/rounds.py` → *"The rule:"*).
- **The review loop is an opt-in pattern over a round.** A round node is a review loop when it declares `writer`, which the schema requires together with `counter` and `convergingFrom`; only a review loop may carry `plan` and `revisionNote` (`graphscene/src/graphscene/schemas/flow-graph.schema.json` → the round node's `dependencies`; `graphscene/src/graphscene/engine/review_loop.py` → *"The rule:"*). **Which round is a review loop is `graphscene/src/graphscene/engine/review_loop.py`'s alone**; the walker and static checker ask it (`graphscene/src/graphscene/engine/walker.py` → *"which round is a review loop is"*; `graphscene/src/graphscene/engine/static_check.py` → *"The rule:"*).
- **A review-loop rule runs only where a graph declares a review loop.** Checks 8 and 9 split into round rules, run on every round, and review-loop rules, run only on a review loop; check 8's graph-wide fail-verdict clause runs only on a graph that declares one (`graphscene/src/graphscene/engine/static_check.py` → *"The rule:"*; `graphscene/README.md` → `## What it is`; `docs/development.md` → **Gate 3**, *"their review-loop rules run only on a round that declares `writer`"*). A new review-loop rule follows the same split.

## What accompanies a new module

- **A module under `graphscene/src/graphscene/` lands in the layer its work belongs to**, per `## The internal layers`, **with its opening docstring**, per `## Naming and layout`, **with its row entry in `graphscene/README.md` → `## What it is`**, **and with its own test suite, `graphscene/tests/<layer>/test_<module>.py`** (`graphscene/README.md` → `## What it is`, the `tests/` row).
- **A name made public lands with** its import and `__all__` entry in both `graphscene/src/graphscene/facade/__init__.py` and `graphscene/src/graphscene/__init__.py`, in the same order, and its `_EXPECTED` and `_DEFINED_IN` entries in `graphscene/tests/test_public_surface.py` (`graphscene/tests/test_public_surface.py` → `_EXPECTED`, `_DEFINED_IN`).
- **A new walk-action or passage variant lands with** its `kind` handled in `graphscene/src/graphscene/adapters/walk_json.py` and a round-trip state carrying it in `graphscene/tests/adapters/test_walk_json.py` (`graphscene/tests/adapters/test_walk_json.py` → *"one per pending-action variant; together they carry every passage kind"*).
- **A new valid graph fixture lands with** its `_FIXTURE_NAMES` entry in `graphscene/tests/test_flow_graph_schema.py` and its listing in the root `package.json` → `validate:graphscene-schema` (`graphscene/tests/test_flow_graph_schema.py` → `_FIXTURE_NAMES`; `package.json` → `validate:graphscene-schema`, the `valid_plain_round.json` entry).
