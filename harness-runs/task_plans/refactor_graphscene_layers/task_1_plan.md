### Task 1 — Move GraphScene's modules and tests into the `model`, `engine`, `adapters` and `facade` layers

**Goal:** Turn the flat `graphscene/src/graphscene/` into four layer subpackages, `model`, `engine`, `adapters` and `facade`, with imports pointing down only and `engine` / `adapters` independent of each other. Move the test suite into matching `tests/model/`, `tests/engine/`, `tests/adapters/` and `tests/facade/` directories in the same change. The package root keeps its `__all__` exactly, and every caller-visible behaviour stays as it is today.

**Where this task stops.** This task moves code and rewires imports. It writes no `import-linter` contract and no layer-contract test: the `[tool.importlinter]` section of `graphscene/pyproject.toml` and `graphscene/tests/test_layers.py` belong to **Task 2**. It does not touch `graphscene/README.md`: the layout table and the layer rules prose belong to **Task 3**, so the README's four module rows stay stale until then. It also does not touch any file outside `graphscene/`. `docs/development.md`, `docs/flow-graph-walker.md` and `devscene.config.json` belong to **Task 4**. Task 2 consumes the module paths this task creates, exactly as named under `### Targets`: its contracts name `graphscene.facade`, `graphscene.adapters`, `graphscene.engine` and `graphscene.model`.

**Two rules every new module follows.** Each is stated once here and holds for every bullet below:

- **No module inside the package imports from the package root** (`from graphscene import …` or `import graphscene`). The root `__init__.py` imports `graphscene.facade`, so a lower layer that imported the root would reach upward and could cycle. A module imports the **defining module** of what it needs, for example `from graphscene.model.errors import Violation` and `from graphscene.model.flow_graph import FlowGraph`.
- **The three lower layer packages' `__init__.py` files re-export nothing.** Each one holds only a module docstring stating what the layer holds and what it may import (`.claude/context/graphscene.md` → `## Naming and layout`: *"A module opens with a docstring stating what it owns and, where it holds a rule, that rule"*). Only `graphscene/facade/__init__.py` and the root `graphscene/__init__.py` re-export.

Code moves **verbatim**: same names, same bodies, same messages. The only new code is the three small functions the `loader.py` split needs (`schema_violations`, `read_json_file`, and the facade's composition of them), each built from lines `loader.py` holds today. The only other new text is the module docstrings: the four layer `__init__.py` docstrings, and the opening docstrings of `model/flow_graph.py` and `adapters/json_file.py`. Every new module under `graphscene/src/graphscene/` opens with a docstring stating what it owns and the rule it holds (`.claude/context/graphscene.md` → `## What accompanies a new module`). A module whose docstring moves with its code keeps that docstring, edited only as the bullets below say. The ECMA-262 translator (`_ecma_pattern`, `_ecma_patterns`) keeps its name and its refusal text, *"which _ecma_pattern does not translate to ECMA-262"*, character for character. `harness-runs/lessons.md` → `## Ports and parallel implementations` (*"A shim … lists the constructs it supports and refuses every other one"*) binds it, and this move changes neither its supported set nor its refusals.

**Work:**

- [ ] **`model` layer.** `model/__init__.py` gets its docstring. It states that the layer holds the typed flow-graph model and the one error shape, and that it imports the standard library only. It also says that a `typing.Protocol` which an adapter implements and the engine drives is declared in this layer, so an adapter never imports the engine. Move `errors.py` to `model/errors.py` unchanged (`Violation`, `Stage`, `GraphError` and the module docstring). `model/flow_graph.py` takes `model.py`'s type aliases and frozen dataclasses (`NodeKind` through `FlowGraph`, the same names and fields). Its docstring states what it owns: the typed, immutable form of a format-4 flow graph, built by `graphscene.adapters.builder.build_flow_graph`. It keeps `model.py`'s *Fixed words* and *Absent keys* clauses as properties of the types. Delete `errors.py` and `model.py`.
- [ ] **`engine` layer.** `engine/__init__.py` gets its docstring. It states that the layer holds checks over a flow graph, imports `model` and the standard library only, and never imports `adapters`. Move `vocabulary.py` to `engine/vocabulary.py` verbatim, changing only its import to `from graphscene.model.errors import Violation`. `vocabulary_violations` keeps its signature, `(graph: Mapping[str, object]) -> list[Violation]`, and still reads the parsed mapping, not the typed `FlowGraph`. Delete `vocabulary.py`.
- [ ] **`adapters` layer.** `adapters/__init__.py` gets its docstring. It states that the layer holds what touches a format or the outside world, imports `model`, `jsonschema` and the standard library, and never imports `engine`. The layer has three modules:
  - `adapters/schema.py` takes `loader.py`'s `_ECMA_DOT`, `_ECMA_SYNTAX`, `_QUANTIFIER`, `_render`, `_ecma_pattern`, `_ecma_patterns` and `_validator` verbatim, together with the ECMA-262 paragraph of `loader.py`'s docstring. `_validator` still reads `files("graphscene") / "schemas" / "flow-graph.schema.json"`, so the schema resolves against the package root. It adds `schema_violations(graph: object) -> list[Violation]`, which is `load_graph`'s current `sorted(… key=lambda violation: (violation.path, violation.reason))` expression returned as a list: `[]` for a schema-valid graph, and it never raises `GraphError`.
  - `adapters/builder.py` takes `build_flow_graph` and its private helpers (`_join` through `_node`) verbatim, together with `model.py`'s mapping-rules docstring. Two docstring edits: *"Validation, which is the loader's"* becomes *"Validation, which is the facade's"*, and the cross-reference becomes `graphscene.model.errors.Violation.path`.
  - `adapters/json_file.py` opens with a module docstring (`.claude/context/graphscene.md` → `## What accompanies a new module`). The docstring states what the module owns: reading a flow-graph file from disk into parsed JSON data. It also states the rule the module holds: the file must be UTF-8 and JSON, a failure raises a parse-stage `GraphError` with today's exact reasons, and an `OSError` propagates unchanged. The module then adds `read_json_file(path: str | os.PathLike[str]) -> object`. Its body is `load_graph_file`'s current read, decode and parse body, unchanged, so it behaves exactly as that docstring states.
- [ ] **`facade` layer and the package root.** `facade/loading.py` holds `load_graph(graph: object) -> FlowGraph` and `load_graph_file(path: str | os.PathLike[str]) -> FlowGraph`, with `loader.py`'s module docstring: its rule, schema then vocabulary then build, and its *"Deliberately not checked"* list.
  - `load_graph` raises `GraphError("schema", found)` when `schema_violations` returns a non-empty list. It then asserts that the graph is a `dict`, raises `GraphError("vocabulary", found)` on a non-empty `vocabulary_violations`, and returns `build_flow_graph(graph)`.
  - `load_graph_file` is `load_graph(read_json_file(path))`.
  - `facade/__init__.py`'s docstring says that it is the composed public surface the package root re-exports and that it may import every layer. It imports every public name from its defining module and declares `__all__: list[str]` holding exactly the root's names, in the root's order.
  - Rewrite `graphscene/__init__.py` so that it imports every public name from `graphscene.facade` and nothing else. Its `__all__: list[str]` stays byte-identical to today's list. Keep its docstring's boundary paragraph, and add that the surface is re-exported from `graphscene.facade` and that no module inside the package imports from the package root.
  - Delete `loader.py`.
- [ ] **Tests mirror the layers.** Each of `tests/model/`, `tests/engine/`, `tests/adapters/` and `tests/facade/` gets an `__init__.py` holding a one-line docstring. Without it, two same-basename test files collide under `pytest`'s default import mode, and `mypy` (`files = ["src", "tests"]`) reports a duplicate module. Every moved file reads fixtures from `Path(__file__).parents[1] / "fixtures" / "flow_graph"`, and its `"The rule this file exists to enforce"` docstring names the new module path. Every test case moves unchanged, apart from its imports. The moves:
  - `test_errors.py` → `tests/model/test_errors.py`, importing `graphscene.model.errors`. Its last case, `test_vocabulary_violations_render_to_the_strings_the_check_returned_before`, moves to the engine file, and its docstring's sentence about that case moves with it.
  - `test_vocabulary.py` → `tests/engine/test_vocabulary.py`, importing `graphscene.engine.vocabulary` and `graphscene.model.errors`. `_NEGATIVES` stays in this file.
  - `test_model.py` → `tests/adapters/test_builder.py`, importing `graphscene.adapters.builder` and `graphscene.model.flow_graph`.
  - `test_loader.py` splits in two. The cases from `test_the_shipped_schema_is_a_valid_draft_7_schema` to the end of the file, with `_refusal`, go to `tests/adapters/test_schema.py`, importing `_ecma_patterns` from `graphscene.adapters.schema`. Every other case, with `_SCHEMA_NEGATIVES`, `_VOCABULARY_NEGATIVES`, `_parsed` and `_node`, goes to `tests/facade/test_loading.py`, importing the public names from `graphscene` as a caller does.
  - In `tests/test_public_surface.py`, `_DEFINED_IN` maps `load_graph` / `load_graph_file` to `graphscene.facade.loading`, `GraphError` / `Stage` / `Violation` to `graphscene.model.errors`, `vocabulary_violations` to `graphscene.engine.vocabulary`, and the rest to `graphscene.model.flow_graph`. `test_the_named_examples_resolve_to_their_modules` names `graphscene.facade.loading.load_graph` and `graphscene.model.errors.Violation`. `_EXPECTED` and `test_the_unvalidated_builder_is_not_exported` stay unchanged. Add `test_the_facade_exposes_exactly_the_root_surface`, asserting `graphscene.facade.__all__ == graphscene.__all__`.
  - In `tests/test_flow_graph_schema.py`, the *"Deliberately not covered"* line names `tests/adapters/test_schema.py` and `tests/facade/test_loading.py` in place of `tests/test_loader.py` / `graphscene.loader`.
