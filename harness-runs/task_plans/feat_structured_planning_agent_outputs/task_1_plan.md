Each variant: `type: "object"`, `description`, `properties`, `required` (always including `outcome`), `additionalProperties: false`. `properties.outcome` is `{ "const": "<value>" }` (plus `description`), and the `const` values are distinct across variants. No other keyword. State that `outcome` is the one discriminator, that its values for a graph-dispatched agent are that node's outcome keys minus `error`, and that `error` is never an agent's outcome: a caller records it.
