Task 13's citation check therefore cannot see it, so renaming `findings_file` in a reviewer's schema would leave this sentence stale with no test failing. That is the run-time drift goal 4 exists to prevent.
   **Fix:** In Task 4's `plan_review_rounds.md` bullet, keep the rule that binds the round file: a plan gate writes and returns the round file on both outcomes. For the field set, either point at each reviewer's `## Return schema` without naming its fields, or name the fields in `## Citing a field`'s form for each of the four reviewers that cite the section (for example `` `task-plan-reviewer.findings_file` ``), so Task 13's check covers them.
