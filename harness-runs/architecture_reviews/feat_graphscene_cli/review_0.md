1. **`task_2_plan.md` puts the check document's encoder, a JSON format, in `facade/cli.py` instead of `adapters`** — offending files: `task_2_plan.md` (the `check <graph>` Work bullet) and `task_1_plan.md` (its Goal and "Where this layer stops"). Rule sources: `.claude/context/graphscene.md` → `## The internal layers` ("New work goes by what it is. … A store, an executor or another format goes in `adapters`. A thin command-line entry point goes in `facade`") and `graphscene/README.md` → `## The layers`, which that document cites. `graphscene/src/graphscene/adapters/__init__.py` makes the same point: adapters is "what touches a format or the outside world".
   The plan correctly puts the step document and the round-resume document in `adapters` (Task 1). It leaves the third wire form, the **check document**, in the command module. Task 2's `check` bullet has `cli.py` build `{"stage": …, "violations": [{"path", "check", "reason"}]}` from a `GraphError` and split each static reason at its first `": "` into `check` and `reason`. That is a mapping from a model type (`GraphError` / `Violation`) to a JSON wire shape, plus a parse of the static stage's reason format. That is a format, and the layer rule sends formats to `adapters`. The story index's own register row 3 counts the check document among the new wire forms. Task 1's Goal limits itself to "the two JSON forms … that belong with the walk codec", and no task gives the check document an owner in `adapters`. As planned, the facade module would hold a codec: the wire shape #459's checker comparison is expected to consume (story `## Context`) could then only be reached by importing the command line, and the shape would have no `adapters` suite holding it.
   **Raised against:** "Call `load_graph_file(Path(graph))` and print `{"stage": null, "violations": []}` with exit `0`, or on `GraphError` print `{"stage": error.stage, "violations": [...]}` with exit `1`." / "Only for `error.stage == "static"`, split `v.reason` at its first `": "` into `check` and `reason`."
   **Must hold:** The check document's encoding (the `GraphError` → `{"stage", "violations": [{"path", "check", "reason"}]}` mapping, including the static check-id split) is owned by a module under `graphscene/src/graphscene/adapters/`, with its own suite under `graphscene/tests/adapters/`. `facade/cli.py` only calls that encoder and writes its result, so the command module stays a thin entry point that re-encodes no wire form.
   **Class:** Broken contract
   **Failure:** If the implementer follows Task 2's `check` bullet, `graphscene/src/graphscene/facade/cli.py` will contain the `GraphError`-to-JSON encoder and the static reason split, so a `facade` module owns a format that `graphscene/README.md` → `## The layers` assigns to `adapters`, and no `graphscene/tests/adapters/` suite covers that wire shape.
   **Fix:** In `task_1_plan.md`, add a third function that encodes the check document: `check_document(error: GraphError | None) -> dict[str, object]`, or an equivalent signature named in both files. It returns `{"stage": None, "violations": []}` for `None`, applies the static-only check-id split, and passes `path` through verbatim. Put it in a new owner file, `graphscene/src/graphscene/adapters/check_json.py`. It has its own opening docstring with *"The rule:"*, its suite at `graphscene/tests/adapters/test_check_json.py`, and hand-written cases (a static violation split, a schema violation with `check: null`, a parse-stage root path `""`, the clean document). If the writer prefers widening `walk_json.py`, it must re-scope that module's docstring explicitly, because the check document is not a walk form. List it under Task 1's Targets and in "Where this layer stops". In `task_2_plan.md`, make the `check` bullet and the walk commands' rejection path call that function and print its result. Add it to "Where this module may reach" and to the Verification bullet *"its only use of the walk JSON forms is calling …"*.
