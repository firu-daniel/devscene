## Should Fix

1. **`task_2_plan.md` / `task_4_plan.md` — `build_flow_graph` is a public-named function that is deliberately kept out of `__all__`.** `.claude/context/graphscene.md` → `## What accompanies a new module` states *"A name the module makes public lands with its `__all__` entry in `graphscene/src/graphscene/__init__.py`"*. Task 2 defines `build_flow_graph` in `graphscene/src/graphscene/model.py` with no leading underscore, and Task 4 pins `"build_flow_graph" not in graphscene.__all__` with the reason *"It assumes a validated graph, and `load_graph` is the public way in."* That intent is sound, but the name still reads as public under the rule, so a per-unit reviewer reading the rule literally can grade the final tree against it. Not graded Must Fix because the document does not define what *"makes public"* means. Suggested fix: state the intent in the name, either `_build_flow_graph` imported by `loader.py` or a module-level `__all__` in `model.py` that omits it. Alternatively, Task 2's module docstring can say explicitly that `build_flow_graph` is package-internal and why. Either way, Task 3's restated contract and Task 4's `test_public_surface.py` case follow the chosen spelling.

2. **`task_1_plan.md`, `task_2_plan.md`, `task_3_plan.md` — public names land one or more units before their `__all__` entries.** The same rule (`.claude/context/graphscene.md` → `## What accompanies a new module`) has each new module's public names land with their `__all__` entries. The plan puts every entry in Task 4, which *"owns `graphscene/src/graphscene/__init__.py` … and no earlier task touches either"*. The branch as a whole satisfies the rule, and the contract-before-consumer order follows `.claude/context/conventions.md` → `### The order files are created, so a half-built feature is still coherent`. Still, the reviewer for Task 1, 2 or 3 grades that unit's diff alone and may ask for the entry early, which would clash with Task 4's sole ownership of `__init__.py`. Suggested fix: add one sentence to each of Tasks 1–3's **Where this task stops.** saying the `__all__` entry for its public names is deferred to Task 4 under that rule, so a unit reviewer reads the deferral rather than inferring it.
